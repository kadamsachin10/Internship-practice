## 3. Objectives of Software Testing

- Software testing is an activity to detect and identify defects in software.
- The objective of testing is to deliver a quality product to the client.

## 4. Role of a Software Tester

- Understand and analyze requirements.
- Identify test scenarios.
- Write and review test cases.
- Execute test cases.
- Identify and report defects.
- Help ensure software quality.

## 5. Software Testing Life Cycle (STLC)

STLC is a step-by-step procedure or approach to test and validate software or applications.

### Test Case Design

- Identification of test scenarios.
- Writing test cases.
- Reviewing test cases:
  - Self-review – By ourselves.
  - Peer review – By teammates.
  - Senior review – By senior team members.
- Fixing comments received during review.
- Approval by Senior QA or Test Lead.

### Requirement Traceability Matrix (RTM)

RTM is used to map requirements to test cases and track test coverage.

### Test Case Execution

Executing test cases and comparing actual results with expected results.

### Defect/Bug Reporting and Tracking

Reporting defects and tracking their status. JIRA is one tool used for bug tracking.

### Reports and Documentation

Maintaining test reports and testing-related documentation.
