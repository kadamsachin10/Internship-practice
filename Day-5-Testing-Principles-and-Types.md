# Day 5 – Testing Principles and Types

## 1. Testing Principles

### 1.1 Early Testing

**Definition:** Early Testing means starting testing activities early to find defects as soon as possible.

**Example:** A tester reviews the requirements and asks the Product Owner if anything is unclear. This helps prevent defects early.

### 1.2 Testing Shows the Presence of Defects

**Definition:** Testing helps us find defects in software, but it cannot prove that the software has no defects.

**Example:** A tester checks the login page and finds that the login button is not working. The tester reports the defect so the developer can fix it.

## 2. Functional Testing

**Definition:** Functional Testing checks whether the software works according to the requirements.

**Example:** A tester enters a valid username and password and checks whether the user can log in successfully.

## 3. Non-functional Testing

**Definition:** Non-functional Testing checks how well the software works, such as its performance, usability, security, and reliability.

**Example:** A tester checks whether the website loads quickly when many users use it at the same time.

## 4. Positive Testing

**Definition:** Positive Testing checks whether the software works correctly when valid input is given.

**Example:** A tester enters a valid username and password and checks whether login is successful.

## 5. Negative Testing

**Definition:** Negative Testing checks how the software behaves when invalid or unexpected input is given.

**Example:** A tester enters an incorrect password and checks whether the system displays an error message and prevents login.

## 6. Difference Between Functional and Non-functional Testing

| Functional Testing | Non-functional Testing |
|---|---|
| Checks what the software does. | Checks how well the software works. |
| Verifies software features against requirements. | Verifies performance, usability, security, etc. |
| Example: Checking whether login works correctly. | Example: Checking how quickly the login page loads. |

## 7. Difference Between Positive and Negative Testing

| Positive Testing | Negative Testing |
|---|---|
| Uses valid inputs. | Uses invalid or unexpected inputs. |
| Checks whether the system works correctly with valid data. | Checks whether the system handles invalid data correctly. |
| Example: Entering a correct password. | Example: Entering an incorrect password. |

## 8. Real-world Examples

| Testing Type | Example |
|---|---|
| Functional Testing | Checking whether the Add to Cart button works. |
| Non-functional Testing | Checking whether an e-commerce website loads quickly. |
| Positive Testing | Logging in with a valid username and password. |
| Negative Testing | Trying to log in with an incorrect password. |

**Important note:** Functional and non-functional testing describe different testing objectives. Positive and negative testing describe approaches to test inputs and system behavior. These categories can overlap in real projects.
