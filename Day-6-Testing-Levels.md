# Day 6 – Testing Levels

## 1. Unit Testing

**Definition:** Unit Testing checks a small part of the software, such as a function or method, separately.

**Who usually performs it?** Developers.

**Example:** In a shopping app, a developer checks whether the function that calculates the total price works correctly.

## 2. Integration Testing

**Definition:** Integration Testing checks whether two or more modules work correctly together.

**Who usually performs it?** Usually developers or testers, depending on the project.

**Example:** In a shopping app, the tester checks whether the Cart module sends the correct order details to the Payment module.

## 3. System Testing

**Definition:** System Testing checks the complete application to verify that it meets the specified requirements.

**Who usually performs it?** Testers.

**Example:** In a shopping app, the tester checks the complete flow: login, search for a product, add it to the cart, make payment, and view the order confirmation.

## 4. Acceptance Testing

**Definition:** Acceptance Testing checks whether the software meets business needs and is ready to be accepted for release.

**Who usually performs it?** Usually the customer, client, or business users. Testers may support them.

**Example:** Before a shopping app is released, business users check whether customers can place orders and receive order confirmations as required.

## 5. Difference Between Testing Levels

| Testing Level | What Is Checked? | Simple Example |
|---|---|---|
| Unit Testing | One small part | Checking the price-calculation function |
| Integration Testing | Connected modules | Checking Cart works with Payment |
| System Testing | The complete application | Testing the full shopping process |
| Acceptance Testing | Whether business needs are met | Client checks if the app is ready to use |

## 6. Easy Way to Remember

- **Unit Testing:** Check one small part.
- **Integration Testing:** Check whether parts work together.
- **System Testing:** Check the complete application.
- **Acceptance Testing:** Check whether the software meets the user's or business's needs.

**Note:** These are testing levels, not testing types. Different testing types, such as functional and non-functional testing, can be performed at different levels.
